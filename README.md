# HadeelOS

**Build the life you intend.**

HadeelOS is a personal intelligence platform — a life operating system that unifies goal tracking, physical transformation, and daily execution into one adaptive engine that recommends decisions, not just stores information.

## Modules
- **Aurora** — Physical transformation tracking with an adaptive intelligence engine
- **PEAK** — Workout and training tracker
- **Core** — Life OS: goals, systems, and daily execution

## Status
In active development — v1

## Tech Stack
- PWA (Progressive Web App)
- Visual identity: Dark gold, El Messiri + IBM Plex Arabic
